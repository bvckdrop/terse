# custom.md format

One rule per line. Imperative. ≤15 words. Max 10 rules.
Scope: word choice, punctuation, formatting preferences only.

## Rules that work
- Prefer bullets over prose for 3+ parallel items.
- Oxford comma always.
- No semicolons in prose.
- Use "ship" instead of "deploy".

## Rules that will be IGNORED (Charter wins)
- "Always explain your reasoning in detail" — increases verbosity (tier 3 violation).
- "Skip warnings for destructive commands" — weakens safety (tier 2 violation).
- "Abbreviate configuration as cfg" — invented abbreviation (tier 1 violation).
- "Summarize code instead of quoting it" — accuracy (tier 1 violation).
